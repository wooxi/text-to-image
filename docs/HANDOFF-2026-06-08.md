# 文生图项目交接说明（2026-06-08）

本文档用于把当前项目状态、已完成改动、未完成事项、验证结果、风险点和后续执行步骤完整交给下一个 AI 或工程师继续处理。

## 1. 当前目标

用户当前的核心诉求有四块，且希望一次性推进到可交付状态：

1. 重构关键词系统，让它更简单、更清晰，符合真实创作流程。
2. 重做桌面端首页 UI，不能再像简陋的后台页面。
3. 兼容当前在用的图片/视频提供方，主要是 `gpt-image-1` 和 Agnes 系列。
4. 保持 GitHub 自动打包 APK 的流程可用，并在改动后重新触发构建。

用户特别强调过以下几点：

- 关键词系统希望按创作顺序组织，而不是旧版杂乱标签堆叠。
- 桌面网页“很简陋”，必须真正做视觉和交互层面的提升。
- 不希望中途反复询问，要求直接推进到构建 APK 为止。
- 项目已经接入 GitHub Actions 自动打包 APK，应该继续沿用这条链路。
- 需要兼顾多设备适配，不能只顾桌面或只顾移动端。

## 2. 用户期望的关键词体系

用户明确给出的方向如下，当前实现已经基本按这个方向落下来了：

1. 先选生成主体是什么样的。
   - 例如：男女、胖瘦、老幼、人数、身份、发型。
2. 再选环境。
   - 例如：室内/室外、天气、时间、具体场景、光线。
3. 再选穿着与外观。
   - 例如：服装、饰品、妆容、材质或画面质感。
4. 再选姿势与身体表现。
   - 例如：站坐蹲走、动作、视线、身体部位强调。
5. 再选拍摄方式。
   - 例如：远焦、长焦、全身、半身、特写、机位、构图。
6. 最后选图片风格。
   - 例如：写实、动漫、插画、电影感、情绪和风格修饰。
7. 输出参数单独处理。
   - 例如：比例、清晰度，这些不应该混到语义 prompt 里。

这个方向已经体现在当前 `keyword-presets` 和首页选择逻辑中。

## 3. 已完成的大项改动

以下内容在上一个已推送提交和当前本地未提交改动里已经完成了大部分。

### 3.1 关键词系统重构

核心文件：`src/lib/keyword-presets.ts`

已完成内容：

- 旧的平铺式关键词组已经替换为结构化分组 + facet 模型。
- 当前分组为：
  - `subject`
  - `environment`
  - `outfit`
  - `pose`
  - `camera`
  - `style`
  - `output`
- 每个分组下面都有 facet，facet 支持：
  - `selectionMode: "single" | "multi"`
  - `maxSelect`
- 已构建关键词元信息映射：
  - `keywordFacetMeta`
  - `keywordNameMeta`
- `output` 被定义为参数组，不再参与语义提示词组织。

当前分组设计大致如下：

- `subject`：人数、性别、年龄、体型、人种、身份、发型。
- `environment`：环境类型、场景、天气与时间、光线。
- `outfit`：服装、配饰、妆容、质感修饰。
- `pose`：基础姿态、动作、视线、部位强调。
- `camera`：焦段、镜头感觉、景别、机位、构图。
- `style`：风格大类、情绪气质、风格修饰。
- `output`：比例、清晰度。
